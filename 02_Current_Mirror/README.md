# Current Mirror

## Objective
To design and analyze a basic MOSFET current mirror and understand its
operation, current matching, output resistance, and limitations.

## Circuit
The circuit uses two matched MOSFETs. One transistor is diode-connected
and establishes the reference current, while the second transistor
mirrors this current at the output.

## Key Concepts

- MOSFET current mirror operation
- Reference current
- Output current
- Current matching
- Channel-length modulation
- Output resistance
- Compliance voltage

## Design Flow

1. Select supply voltage and reference current.
2. Calculate the required MOSFET dimensions.
3. Construct the current mirror schematic.
4. Perform DC simulation.
5. Measure reference and output currents.
6. Analyze current-matching error.
7. Study the effect of output voltage.
